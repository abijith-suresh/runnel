# Runnel MongoDB

`@abijith-suresh/runnel-mongodb` is a public package boundary for the future MongoDB
adapter. It depends on Runnel core, Effect v4, and the official MongoDB Node driver.

This development baseline exports an empty module. It creates no clients, pools,
or connections and implements no provider behavior. Build with `npm run build`
at the repository root.

See [the repository](https://github.com/abijith-suresh/runnel) for design and
development documentation. This package has not been published.
